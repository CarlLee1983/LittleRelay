# 定義人工付款與寄送規則

Type: grilling
Label: wayfinder:grilling
Status: resolved
Blocked by: 01

## Question

第一版在什麼地區營運、支援哪些人工付款與寄送方式？結帳時如何固定商品售價、運費與應付總額，如何提供付款指示或辨識資訊、處理顧客付款回報與核對入帳、查無款項時重設期限、逾期或未收款取消後才入帳、改價、整單取消、退款處理中與已完成後的退貨例外？已釋出的商品若已轉售，如何對帳與退款？寄送失敗時如何處理？顧客和店家各需要收到哪些通知，哪些步驟留在網站外？

已確認網站會接收「逾期款項回報」供管理員人工核對，但不恢復訂單或保留；本票決定後續對帳、退款與通知方式。

## Comments

- 店家確認首店只服務台灣本島、以新台幣計價；首版只收銀行轉帳，支援超商店到店與面交。每店自訂每單一次的超商運費，面交運費為零；不做折扣碼、滿額免運或網站自動稅額計算。
- 顧客回報轉帳金額、時間與帳號末五碼；管理員以實際入帳逐筆對帳。少付可人工追蹤補款，多付先退差額；未完成對帳或退款時不釋出商品。逾期或取消後才入帳預設退款，符合條件才另建新單。
- 店家選擇網站查單與人工通知，超商必要資料及每單聯絡手機於結帳收集；面交時間地點在站外約定。超商未取可協議重寄或退款，確定遺失／重大損壞先退款，物流求償另辦。
- 首店以個人出售自家二手衣為預設，但仍自願提供簡單的收貨後七日退貨流程；顧客在訂單頁留訊，管理員人工處理。整單退原支付總額；部分退貨退該件原價，原訂單運費保留；退件運費由店家負擔。正在處理的售後案件延後私有照片清除，結案後三十天再清。
- 店家已確認以下整體規格。

## Answer

### 營運範圍、結帳與交付資料

- 首店只接受台灣本島可寄達門市或雙方約定面交，以 TWD 整數金額計價；**首店啟用 7-ELEVEN、全家及面交**。複製店可選擇啟用其中一種或兩種超商品牌與面交；不串接物流平台，店家人工核對門市可寄並辦理寄件。已知不支援的品牌、門市或服務區域不得送單；門市臨時失效則依下述交付例外處理。面交地點和時間由雙方站外約定，不在結帳時收住址。
- 結帳總額＝各商品送單時價格合計＋該店當時設定的**每單一次**超商運費；面交運費為零。沒有折扣碼、滿額免運、貨到付款、分期或線上金流。送單交易檢查顧客確認的交付政策版本（啟用品牌／面交、服務範圍與運費）、實際選定的門市是否仍合規，以及付款指示版本；若期間變更或選項失效則不成單、請顧客重新確認。成功後固定幣別、各商品價格、交付方式、運費、應付總額與付款指示版本。之後調價或調運費不重算舊單。付款、交付和退貨規則在送單前清楚顯示，訂單保留當時版本供顧客查閱。[結帳一致性](07-checkout-consistency.md)
- 超商訂單收取收件姓名、聯絡手機、超商品牌和取件門市識別資料；面交訂單也收聯絡手機。只在已登入的該訂單顧客與有權限管理員之間顯示資料，保存與刪除期限交由[顧客與配送資料生命週期](09-customer-data.md)決定。門市失效時先聯絡買家換有效門市，不擅自加價或寄往其他地點。
- 店家在部署時提供一個收款帳戶及付款說明，發布為 D1 中的現行付款指示版本；交付品牌、服務範圍與運費也以 D1 現行版本為準，設定更新須在 D1 推進版本，不能只改環境變數或靜態頁面後宣稱結帳使用新設定。訂單頁只對該顧客顯示應付金額、唯一訂單編號、收款資訊和確切付款截止時間。可請買家在轉帳備註寫訂單編號，但不能只靠備註對帳。店家換收款帳戶時，新單使用新指示；舊單保存原指示。若舊帳戶無法再收款，管理員須為指定舊單明確記錄新版指示並人工通知買家，保留修改前後與通知紀錄，不暗改應付總額。舊帳戶可能已有入帳，仍須對帳。

### 人工對帳、付款異常與取消

- 顧客在截止前於訂單頁回報轉帳金額、轉帳時間和轉出帳號末五碼，不上傳收據截圖；重送相同回報不可重複產生已收款效果。回報只將訂單轉「付款待核對」並暫停到期，**不是已收款**。若顧客未回報，但管理員在截止前核對到可歸屬該單的部分或待釐清入帳，管理員須在同一 D1 交易中記錄帳目、將該單轉「付款待核對」，不能任其自動到期。金額、時間與末五碼只是配對線索，不能當成銀行入帳的唯一識別。店主或管理員查看銀行對帳單，為每條實際入帳建立可追查且在該店唯一的帳目識別：優先使用銀行交易編號；沒有時以**不可變的對帳單文件識別**及該文件列序建立內部識別。不同文件若期間重疊或重匯出後列序改變，須先比對既有帳目，無法排除重複時保持待釐清，不得用新內部識別直接確認第二筆。資料庫使同一已確認帳目只能歸屬一張訂單，兩位管理員同時認領也只有一個結果；兩筆相似入帳或來源不明時先列為待釐清，不能靠末五碼猜測確認收款。紀錄金額、時間、遮罩參考與操作者；管理員不得確認自己的付款。[權限規則](04-buyer-approval.md)
- 核對到剛好足額後，管理員才確認收款；商品於此時售出並清除公開照。可將多次補款逐筆對應同一訂單，但總額不足時維持保留及人工追蹤，管理員設定補款追蹤期限；此期限不是會自動釋出庫存的原待付款期限。未補足則先退回全部已收款，再由管理員取消。多付時先退款差額並記錄，才確認該單足額。退款失敗、退款帳戶待核對或結果不明時保持待辦及不可購買，不宣稱已退、不釋出商品。已收款後的重複轉帳另開退款待辦，不改原訂單金額。
- 對帳與退款須有逐筆帳本：每筆銀行入帳只能認領一次。**人工匯款前**，管理員先在 D1 原子建立帶操作識別與金額的專屬退款意圖，保留可退額度；可新開退款額＝已確認入帳總額－已成功退款－進行中或結果不明的退款保留額。兩位管理員競爭時只允許一方取得同一筆可退餘額，不能先各自匯款再讓 D1 拒絕第二筆紀錄。每個退款意圖再由**唯一執行人**於 D1 原子認領，只有該執行人能查看完整退款帳戶與標記該次匯款結果；其他管理員只看遮罩、金額和處理狀態，不可再次執行同一意圖。認領及開始匯款均留操作紀錄；若執行人中斷、撤權或銀行結果不明，不因時間到自動釋放認領／額度。店主先核對銀行是否實際匯出，才能將同一意圖交接給另一有權管理員作**核對或尚未匯出時的執行**；查不清時保持鎖定，不再匯款。匯款成功後核對銀行交易參考並將意圖確認為已退款；只有銀行證實未匯出／失敗時才釋放保留額，結果不明時持續保留並人工查證，不得重匯。每張訂單累計**成功與保留中的退款額不得超過已確認入帳總額**；每件商品的售後退貨亦計入已退與保留額，不能對同一件重複退款。若先退單件，之後其餘商品也退，第二次只退仍未退或未保留的商品與尚未退／未保留的原運費，使整張訂單至多退回當初實收；後續全單遺失或其他全額退款也只處理剩餘可退餘額。若另收重寄運費，獨立記錄其入帳與處理，不改原訂單快照。
- 顧客回報後若查無入帳，管理員可明確設定新的付款截止時間、讓訂單回到待付款，或在確認無未處理款項後取消；舊截止時間不得無聲重新生效。若查到任何已入帳款項，先按上項完成補正或退款，不將其當作純未付款單釋出。[訂單生命週期](01-order-lifecycle.md)
- 顧客的逾期款項回報及銀行在逾期／未收款取消後入帳都建立人工對帳待辦，不恢復原單或原商品保留；預設核對並退款。只有買家同意、且**全部**原商品在新的結帳交易中仍可售時，才能明確建立新單，不能搶回已轉售商品或沿用舊送單嘗試。[結帳一致性](07-checkout-consistency.md)
- 已收款但尚未寄出或面交時，顧客可在訂單頁要求取消；管理員停止交付，依既定狀態進入「退款處理中」，人工退回原支付總額並核對衣況後才取消。未收款訂單仍只有管理員主動取消。網站沒有銀行入帳串接，**無法阻止未知、未回報的轉帳隨訂單到期而釋出商品**；若管理員在截止前已於 D1 記錄可歸屬該單的入帳，則須先轉「付款待核對」，不得再把它當成純未付款單釋出。到期後才發現的入帳走逾期款項流程，不回收已釋出的商品。[訂單生命週期](01-order-lifecycle.md)
- 退款帳戶由該訂單的已登入顧客提供，管理員再用既有聯絡方式核對收款人與帳戶；實際匯出後記錄退款金額、日期、交易參考、遮罩帳號及操作者。完整帳戶只留到退款作業所需，具體保護與刪除由[顧客與配送資料生命週期](09-customer-data.md)決定。退款及付款確認都不得由購買者本人以管理員身分操作。

### 寄送、通知與售後

- 收款確認後才寄件或面交。管理員人工記錄超商品牌、門市、交寄日期與追蹤編號，或面交交付日期；依既定生命週期，交寄／交付即將訂單標為「已完成」，不等待網站上的收貨確認。另依超商取件紀錄或面交紀錄人工記下**實際收受日**；日期不明時先查核，不用推估寄出日自動拒絕售後訊息。[訂單生命週期](01-order-lifecycle.md)
- 網站訂單頁是顧客查付款、交付與售後紀錄的固定入口。店家人工通知收款確認、交寄和追蹤資訊、付款異常、退款、配送異常及付款指示變更；建立訂單與待付款倒數由網站顯示，不串 LINE 推播或簡訊。每次人工聯絡記錄時間與結果。每單留手機供聯絡，既有私人 LINE 聊天可輔助；**LINE Login user ID 不是可直接開啟私人聊天的 LINE ID**。[LINE user ID 說明](https://developers.line.biz/en/docs/messaging-api/getting-user-ids/)
- 首店自願提供實際收受後七日內的簡易退貨通知入口；顧客可在訂單頁送出退貨／售後訊息並留下時間，管理員聯絡退件與退款。七日以收受日次日起算；末日遇休息日及適用法定規則須人工核對，網站不因無物流串接而自動駁回。[官方期間計算說明](https://www.vac.gov.tw/cp-2184-11064-1.html) 七日內整單退貨原則上退回原支付總額，仍須扣除同單先前已成功退款部分；多件訂單只退其中一件時退該件原商品價，其他商品仍保留原單運費；退件運費由店家負擔。商品描述不符、未揭露瑕疵或配送損壞，即使晚於七日仍受理人工查核。收到退件後，管理員核對衣況及退款帳戶，於十五日內完成人工退款；失敗則維持售後待辦。原「已完成」事件與訂單金額快照不覆寫，退款另記為售後案件。
- 已付款但交付前的取消也由顧客於訂單頁通知、管理員執行退款；顧客不能直接修改訂單狀態。超商未取退回後，若買家同意重寄，因買家未取件而增加的第二次運費先由買家支付；店家填錯或配送方失誤由店家處理費用。若不重寄，收到並檢查退件後退款原支付總額。確認寄送中遺失或重大損壞時，先退原支付總額，店家自行向物流求償，不以求償完成為買家退款前提。上述情況均保留原訂單歷史並以售後案件記錄；未實際收回且確認衣況前，商品不重新上架。
- 已售商品若退款後仍適合再售，仍須按[本地上架工作流](06-local-publishing.md)重新確認現況並補公開照片，再由管理員恢復；退款或退件本身不自動恢復庫存。進行中的售後案件暫緩清除該訂單私有照片；結案後三十天清除，並更新[儲存邊界](05-data-image-boundary.md)。售後文字資料保留期限另由[顧客與配送資料生命週期](09-customer-data.md)決定。

### 適用規則與驗收

- 本範本以偶爾出售自家二手物品的個人戶為首店情境，七日退貨是此店主動提供的政策；不能因此宣稱所有複製店都不受消保法規範。台灣官方資料區分偶發個人出售與以販售為業的經營者；適用通訊交易規則的店家有七日解除權及收回／退款等義務。複製店在公開販售前須核對自己的營業性質、地區與法定告知及退貨要求，不能用範本預設值排除法定權利。[經濟部中小及新創企業署資料](https://www.sme.gov.tw/consumer/files/5053/6ACB6D9B-2ADE-48F2-8C54-A5086060B323)、[消費者保護法第 18、19、19-2 條](https://www.ey.gov.tw/Page/4FF303AE95592945/f65a641d-d096-48c1-b357-435ac7786e72)、[台中市政府運費說明](https://www.taichung.gov.tw/3213929/post)
- 驗收至少覆蓋：送單同時停用超商品牌／面交或變更服務範圍、運費、收款指示須重新確認；舊單仍有正確快照；同一銀行入帳被兩單或兩位管理員同時認領、同一對帳單重看／重匯入、重疊期間以不同文件重匯出、兩筆金額與末五碼相同但來源不同或無法辨識時維持待釐清；重複付款回報與重複確認；截止前管理員辨識部分入帳對上自動到期、補款追蹤期限已到、多付與退款失敗；截止前回報但查無入帳、買家已轉帳卻未回報而自動到期釋出、逾期後才發現入帳且商品已轉售；門市失效、未取退件後重寄／退款、配送遺失；收貨日不明與七日邊界、先退一件後再退整單及同時兩筆退款的累計上限、**同一退款意圖被兩人同時開啟／認領、執行人中斷後交接、銀行結果不明**、已完成後退款、進行中案件跨過照片清理期限；管理員處理自己訂單與人工通知漏記。每例檢查訂單快照、入帳唯一歸屬、售後紀錄、商品是否仍可買、退款及照片保留結果。
