# 定義商品與訂單的生命週期

Type: grilling
Label: wayfinder:grilling
Status: resolved

## Question

對單件二手衣，加入購物車、送出訂單、人工確認付款、寄送、取消與售出各代表什麼狀態？何時起其他顧客不能購買，未付款或取消時如何恢復可售？列出顧客與管理員在各狀態可做的動作及例外情境。

## Comments

- 已確認：購物車不占庫存；送出訂單時同張訂單的所有商品必須全部成功保留，否則不成立訂單；成立的訂單初始狀態為待付款，由店家人工核對付款。
- 已確認：管理員確認收款時商品成為售出；保留中仍在公開頁標示但不能加入購物車，收款後從公開列表移除；所有取消都由管理員處理，顧客不自行取消。
- 已確認：每間商店可選擇待付款保留 1、2 或 3 天；期限到時由系統自動結束未付款訂單並釋放商品。取消與逾期是不同原因。
- 已確認：範本預設保留 2 天，管理員可在到期前延長；顧客於期限內回報付款後進入「付款待核對」，暫停自動到期直到管理員核對；未收款取消可恢復可售，已收款取消須先人工退款並確認商品狀況；寄出或面交交付時訂單完成。
- 已確認：管理員查不到顧客回報的款項時，可重設付款期限或取消；逾期後才收到的付款不會自動恢復原訂單，由管理員退款或確認所有商品仍可售後建立新單；第一版不支援部分取消，多件商品須整單取消再重建。

## Answer

### 商品與訂單

- 每件商品只有一件庫存。加入購物車不保留商品；保留中仍公開標示，但不能加入購物車。確認收款後商品視為售出，從公開列表移除。
- 顧客送出多件商品時，全部商品必須一同成功保留，才建立一張「待付款」訂單；任一件不可售就不建立訂單，也不保留其他件。訂單不支援部分取消。
- 每張待付款訂單在建立時取得確切截止時間。每店可選 1、2 或 3 天，範本預設 2 天；日後改店鋪設定只影響新訂單，管理員可在既有訂單到期前延長。截止時間與回報付款同時發生時的原子規則由[結帳一致性票](07-checkout-consistency.md)定義。

### 狀態轉換

| 目前狀態 | 事件與操作者 | 下一狀態及商品結果 |
| --- | --- | --- |
| 待付款 | 顧客在截止前回報付款 | 付款待核對；暫停自動到期，商品維持保留 |
| 待付款 | 管理員在截止前記錄可歸屬該單的部分或待釐清入帳 | 付款待核對；暫停自動到期，商品維持保留直到補正或退款 |
| 待付款 | 管理員直接確認已入帳 | 已收款；商品成為售出並從公開列表移除 |
| 待付款 | 截止時仍無有效付款回報，且沒有管理員在期限內記錄的待核入帳 | 已逾期；整張訂單的商品恢復可售 |
| 待付款 | 管理員取消 | 已取消；整張訂單的商品恢復可售 |
| 付款待核對 | 管理員確認收款 | 已收款；商品成為售出並從公開列表移除 |
| 付款待核對 | 管理員查無款項並給新期限 | 待付款；使用新的截止時間，恢復自動到期 |
| 付款待核對 | 管理員確認沒有未處理入帳，或已完成必要退款後取消 | 已取消；整張訂單的商品恢復可售 |
| 已收款 | 管理員確認寄出或面交交付 | 已完成；不另等顧客於網站確認收貨 |
| 已收款 | 管理員決定取消 | 退款處理中；商品仍不可購買 |
| 退款處理中 | 管理員完成退款與商品狀況確認 | 已取消；僅在仍適合販售時由管理員重新上架，否則維持下架 |
| 已完成 | 顧客提出退貨或發生配送異常 | 維持已完成，另開售後案件；退款與重新上架依人工規則處理 |

顧客不能自行取消，所有主動取消均由管理員處理；系統自動逾期是獨立的結束原因。網站不串銀行資料；沒有在期限內回報、也沒有被管理員記錄的轉帳可能在訂單自動到期後才被發現，這類款項依[人工付款與寄送規則](10-manual-payment-shipping.md)退款或在全部商品仍可售時另建新單，不因入帳自動恢復舊單，也不能搶回已轉售商品。顧客可在訂單頁提出取消或退貨訊息，管理員依同一規則處理，已完成訂單的售後案件不抹除原完成紀錄。付款待核對不能無聲地重新啟動原截止時間，須由管理員重設新期限或取消。每個管理員變更應留可追查紀錄；錯誤轉換以明確後續操作修正，不直接抹除訂單歷史。
