# Cloudflare 與 GitHub：小型二手衣目錄的免費額度查證

查證日期：2026-10-05。以下是官方文件當時列出的條件；「適用性」是依少量單件商品、公開瀏覽、在本機整理後發布所作的推論，並非方案決定。

| 路徑 | 免費額度與超額行為 | 本機發布與照片影響 |
| --- | --- | --- |
| Workers Static Assets | 靜態資產請求免費且不限次數，儲存資產無額外費用；免費版每個 Worker 版本最多 20,000 個檔案、單檔 25 MiB。只有請求進入 Worker 程式才計入 Workers 額度。若使用 `run_worker_first`，超過免費請求額度時，符合該規則的請求會回 429，不會自動退回靜態資產。[資產計費](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)、[Workers 限制](https://developers.cloudflare.com/workers/platform/limits/) | Wrangler 會把設定目錄中的 HTML、CSS、照片等資產與 Worker 一起部署。適合從本機產生整站後發布的模式；每次改照片須重新部署資產。[資產部署](https://developers.cloudflare.com/workers/static-assets/) |
| Cloudflare Pages | 純靜態請求免費且不限次數；Pages Functions 請求則共用 Workers 免費額度。免費版每月 500 次 Git 建置、一次一個建置；每站最多 20,000 檔，單檔 25 MiB。加上 Functions 時，預設所有請求會觸發 Function，需以 `_routes.json` 排除靜態路由。[Functions 計費](https://developers.cloudflare.com/pages/functions/pricing/)、[路由](https://developers.cloudflare.com/pages/functions/routing/)、[Pages 限制](https://developers.cloudflare.com/pages/platform/limits/) | Direct Upload 可用 Wrangler 或拖放從本機發布，不必 Git 整合；Wrangler 上傳上限 20,000 檔、拖放 1,000 檔。Direct Upload 專案日後不能直接切換 Git 整合，需新建專案。[Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/) |
| Workers 動態請求 | 免費版每日 100,000 次 Worker 請求，午夜 UTC 重置；每次 HTTP 請求 CPU 上限 10 ms。超過每日次數會出現 1027；路由可設 fail open（略過 Worker）或 fail closed（回錯誤），但靜態資產的 `run_worker_first` 情況有上述 429 規則。超過 CPU 上限會回 1102。[Workers 限制](https://developers.cloudflare.com/workers/platform/limits/) | 若目錄完全預先產生，公開瀏覽不需動態請求；若每次瀏覽都執行程式，流量與 CPU 限制便成為可用性條件。這是由上述計費與路由規則推論。[資產計費](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/) |
| D1 | 免費版每日讀取 500 萬列、寫入 10 萬列、總儲存 5 GB；最多 10 個資料庫、單庫 500 MB。讀寫額度用完後，查詢會失敗至午夜 UTC 重置；儲存額度用完後，需清理資料才可新增或修改資料結構。[D1 計費](https://developers.cloudflare.com/d1/platform/pricing/)、[D1 限制](https://developers.cloudflare.com/d1/platform/limits/)、[2026-09-01 強制執行公告](https://developers.cloudflare.com/changelog/product/d1/) | 適合需要即時修改商品資料的路徑，但要有 Worker／Function 查詢及發布流程；單純本機產生靜態目錄不會用到 D1。此為架構推論。[D1 文件](https://developers.cloudflare.com/d1/) |
| R2 標準儲存 | 每月免費 10 GB-month、100 萬次 A 類操作（含上傳）、1,000 萬次 B 類操作（含讀取），網際網路輸出流量免費；超出免費量依用量計費，免費額度不適用 Infrequent Access。刪除物件屬免費操作。啟用前需在 Cloudflare 帳號完成 R2 訂閱結帳流程。[R2 計費](https://developers.cloudflare.com/r2/pricing/)、[開始使用](https://developers.cloudflare.com/r2/get-started/) | 照片可作為獨立物件上傳或刪除，無須把照片寫入 Git 歷史；公開桶可用自有網域，`r2.dev` 僅供開發且會限速，自有網域可使用快取。這增加一個需管理的儲存服務與可能的超額費用。[公開桶](https://developers.cloudflare.com/r2/buckets/public-buckets/)、[R2 限制](https://developers.cloudflare.com/r2/platform/limits/) |
| Git 儲存庫圖片／GitHub Pages | 一般 Git 檔案超過 100 MiB 會被拒；GitHub 建議儲存庫最好低於 1 GB、強烈建議低於 5 GB。GitHub Pages 免費帳號須用公開儲存庫；已發布網站最多 1 GB、每月流量軟上限 100 GB、每小時建置軟上限 10 次；超額可能停止服務或收到調整建議。Pages 不支援 Git LFS。[大型檔案](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)、[Pages 限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)、[Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage) | 可在本機改檔後推送到發布分支，或由 Actions 建置發布；但從目前版本刪除照片的 Git commit，舊照片仍留在 Git 歷史。清除歷史需重寫並協調複本／fork；GitHub 對非敏感資料不提供支援清除。因此若會因售出、隱私或授權要求撤除舊照片，Git 追蹤照片有長期留存代價。[發布來源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)、[刪檔](https://docs.github.com/en/repositories/working-with-files/managing-files/deleting-files-in-a-repository)、[清除歷史](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository) |

## 會改變選擇的條件

- **只需本機上架與公開瀏覽**：預先產生目錄時，Workers Static Assets 或 Pages 的靜態請求均不消耗 Workers 每日請求額度；Pages Direct Upload 還可省去 Git 發布步驟，但其整合方式日後不能原地轉換。[Workers 資產計費](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)、[Pages 計費](https://developers.cloudflare.com/pages/functions/pricing/)、[Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)
- **需要即時改庫存、後台或搜尋**：動態請求會受 Workers 每日次數與 CPU 限制；若用 D1，還要計算資料列掃描與每日讀寫失敗邊界。[Workers 限制](https://developers.cloudflare.com/workers/platform/limits/)、[D1 計費](https://developers.cloudflare.com/d1/platform/pricing/)
- **希望照片可獨立移除或避免 Git 歷史累積**：R2 物件儲存可獨立管理照片，但須完成訂閱且超額可收費；Git 圖片在普通刪檔後仍存在歷史中。[R2 開始使用](https://developers.cloudflare.com/r2/get-started/)、[R2 計費](https://developers.cloudflare.com/r2/pricing/)、[GitHub 刪檔](https://docs.github.com/en/repositories/working-with-files/managing-files/deleting-files-in-a-repository)
