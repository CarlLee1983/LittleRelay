# 03: Access 店主入口與首次啟用

**What to build:** 店主透過受 Cloudflare Access 保護的獨立入口完成一次性安全啟用，之後能查看自己的店主狀態。未通過 Access 或已失去 D1 店主權限的人，不能靠舊 session、其他主機或偽造標頭進入店主功能。

**Blocked by:** 01: 可複製的空白商店。

**Status:** ready-for-agent

- [ ] 整個店主 Worker 受 Access 保護；伺服器驗證 JWT 的簽章、簽發者、受眾及期限，並查詢該店目前 D1 店主授權。
- [ ] 空白範本沒有預設店主；首次建立採一次性、受保護且可追查的程序，重試不產生第二位未核對店主。
- [ ] 已驗證店主可看到自己的入口；匿名者、錯誤或過期 JWT、另一店身分、偽造標頭與未知 Host 均被拒絕。
- [ ] 店主在 D1 撤權後使用舊 session，下一次特權請求被拒；D1 無法確認權限時同樣拒絕。
- [ ] 店主失去 Access 入口時的恢復說明指向該店 Cloudflare 帳號，不建立 LINE 管理員自動接管或未驗證緊急入口。
- [ ] 從店主 HTTP 入口與隔離測試 D1 可重跑驗證上述結果，並實測自訂、平台預設、版本與預覽網址沒有繞過整站保護的入口。
