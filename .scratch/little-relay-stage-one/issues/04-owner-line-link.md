# 04: 店主與 LINE 顧客身分關聯

**What to build:** 同時持有店主與 LINE 顧客身分的人，能經兩邊驗證後建立可查的身分關聯。後續管理動作可據此辨識店主自己的顧客紀錄，而關聯本身不授予購買資格。

**Blocked by:** 02: LINE 待核准顧客登入；03: Access 店主入口與首次啟用。

**Status:** ready-for-agent

- [ ] 店主只有在目前 Access 與 D1 店主身分均有效、且 LINE 身分也經本站驗證後，才能將兩者關聯。
- [ ] 關聯使用穩定的商店／provider／channel／LINE user ID，不依顯示名稱、手填 ID 或未驗證的瀏覽器資料。
- [ ] 店主可看到自己的關聯狀態；重送同一關聯不產生衝突紀錄，另一店或另一位店主不能認領已不相符的身分。
- [ ] 建立關聯不改變該顧客的待核准狀態，也不授予管理員或購買資格；失敗時兩種身分與既有權限保持原狀。
- [ ] 關聯及其拒絕結果可從兩個 HTTP 身分入口和隔離測試 D1 驗證；後續自我操作檢查可使用目前的權威關聯。
