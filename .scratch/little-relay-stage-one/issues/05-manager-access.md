# 05: 管理員授權與撤銷

**What to build:** 店主能核對已登入的 LINE 使用者並授予或撤銷管理員角色；管理員能看到自己的當前後台資格。撤權立即影響下一次特權請求，在途操作依 D1 提交先後決定，且管理員不能授權自己或其他人。

**Blocked by:** 04: 店主與 LINE 顧客身分關聯。

**Status:** ready-for-agent

- [ ] 只有目前經 Access 與 D1 雙重確認的店主能為該店已驗證 LINE 身分授予或撤銷管理員；角色與顧客購買資格彼此獨立。
- [ ] 店主能看到授權結果與必要操作紀錄；紀錄包含操作者、對象、時間、原因及結果，不洩漏不必要的顧客資料。
- [ ] 管理員可從公開 Worker 的登入身分查看自己的當前角色；普通或已撤權顧客無法進入管理員操作，管理員不能授予、撤銷角色或處理自己的身分。
- [ ] 授權及撤銷在同一 D1 交易檢查商店、操作者當前權限、目標狀態與自我操作限制，並一同提交角色變更及操作紀錄；條件更新零筆使整筆交易回滾。
- [ ] 撤權先提交時，舊 session 或已進入 Worker 的管理員特權寫入不得提交；合法動作先提交則保留其結果和紀錄。
- [ ] D1 故障、跨店身分、錯誤 Host、無效 LINE 或 Access 憑證均使特權寫入失敗，不以快取或瀏覽器角色補授權。
- [ ] 透過兩個 Worker 的 HTTP 入口與真實隔離測試 D1，驗證授權、撤權、重送、零筆回滾、並發先後、舊 session 及權限紀錄一致；正式營運寫入仍受下一階段門檻阻擋。
