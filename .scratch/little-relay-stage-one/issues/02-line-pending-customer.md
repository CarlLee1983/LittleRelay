# 02: LINE 待核准顧客登入

**What to build:** 訪客先看到該店現行個資告知，再使用該店 LINE channel 登入。首次登入成為待核准顧客並取得申請編號；再次登入看到原申請狀態，沒有自動購買或管理權。

**Blocked by:** 01: 可複製的空白商店。

**Status:** ready-for-agent

- [ ] 登入前顯示目前 D1 個資告知；告知不可讀時不開始新登入或建立顧客紀錄。
- [ ] 登入回呼驗證請求狀態、防重放資訊及伺服器取得的 LINE token，並只接受本站預期 provider／channel 的使用者 ID。
- [ ] 首次合法登入只建立一筆待核准顧客與申請編號；相同身分再次登入返回同一申請及當前狀態，顯示名稱不作授權鍵。
- [ ] 未登入、錯誤 channel、錯誤或過期 token、重放回呼及跨店身分均不能取得他人的申請或新增購買／管理權。
- [ ] 顧客頁只顯示本人必要資料；不要求頭像、Email 或好友清單，也不在網址、靜態資產或一般日誌暴露 LINE ID。
- [ ] 從公開 HTTP 入口和隔離測試 D1 可重跑驗證首次登入、重複登入、失敗封閉及資料隔離；真實測試 LINE channel 的連線流程有可檢查的冒煙驗證。
