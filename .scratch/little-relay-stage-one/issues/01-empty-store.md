# 01: 可複製的空白商店

**What to build:** 店主能從乾淨範本建立互不串接的正式與測試商店；訪客可看到基本公開頁，未啟用的店主入口與正式營運寫入保持關閉。這張票交付可重跑的空白商店起點，讓後續身分功能有安全且可驗證的落點。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 新店設定清楚區分商店與環境；正式和測試的公開商店 Worker、店主 Worker、主機、D1、R2 與 LINE channel 不共用資料或秘密。
- [ ] 空白商店的版本化 D1 遷移可重跑；初始化後沒有首店顧客、角色、訂單、商品照或可用憑證。
- [ ] 匿名訪客可在預期公開主機看到基本商店頁，且單純瀏覽不建立顧客紀錄；未知 Host 被拒絕。
- [ ] 店主 Worker 在 Access 店主入口完成前拒絕所有未授權存取；公開 Worker 不提供店主專屬路由。
- [ ] 正式環境在備份與暫停閘尚未驗收前拒絕營運寫入；正式預設與版本預覽入口沒有繞過此限制的可達路徑。
- [ ] 操作說明與可重跑檢查能以合成資料驗證空白商店、環境隔離、主機拒絕及正式寫入關閉；實際設定及秘密不進範本。
